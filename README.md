# Sistema de Gestión de Perros

Sistema completo para administrar perros, dueños y veterinarios utilizando arquitectura modular en Python.

## Características

- Gestión completa de perros (registro, consulta, actualización)
- Administración de dueños de mascotas  
- Control de veterinarios y especialidades
- Arquitectura modular con separación de responsabilidades
- Implementación de patrones de diseño (Repository, Service)

## Tecnologías

- Python 3.8+
- Patrón Repository para acceso a datos
- Patrón Service para lógica de negocio
- Arquitectura por capas
